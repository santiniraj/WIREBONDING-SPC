# Data folder

`SPC_Events_Anonymous.csv` is the default source dataset for the unified project.

It contains anonymized event-level WP, BS and SP records for the full population used before study-population selection. It is sufficient to reproduce the thesis pipeline without the original company workbook.

`FAILURE_MODE_MAPPING.csv` is used only when an approved physical meaning / PASS-FAIL interpretation for break-mode codes A-E is available. Do not invent this mapping.
